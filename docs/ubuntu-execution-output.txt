5. JOIN OPTIMIZATION TECHNIQUES
================================================================================
A. Broadcast small tables
   Use broadcast() for small lookup or dimension tables.
B. Repartition data
   Repartition large datasets by the join key to reduce shuffle overhead.
   Example: df.repartition("CountryCode")
C. Sort and bucket data
   Pre-sort and bucket data on frequently used join keys.
D. Filter early
   Apply filters before the join to reduce dataset size.
